# Validation Protocol

Every claim is assessed in this order.

1. **Validation input**  State each observational value, constant, boundary condition, or external equation.
2. **WRRA specific transformation**  Identify the owner, renderer, and frozen map used by WRRA.
3. **Output**  Report the calculated value, curve, relation, or qualitative structure.
4. **Falsification condition**  Declare what result rejects or sharply weakens the map.

## Freeze before validation

- topology or global identification class
- distributed twist connection and local twist rate
- evolution equation for $\Theta$
- holonomy to residue map
- constitutive stress map
- photon transport kernel
- weak field and plane director equations
- universal constants and nuisance parameters
- train and held out split
- numerical failure thresholds

## Required joint domains

| Domain | Minimum observable |
|---|---|
| Supernovae | Spectral redshift distance and $1+z$ time dilation |
| Metric light propagation | Distance duality and Tolman dimming |
| BAO | Radial and transverse distances |
| CMB | Spectrum temperature scaling peaks polarization and lensing |
| Direct expansion | Redshift drift |
| Structure | Matter power growth and redshift space distortions |
| Lensing | Galaxies clusters and weak lensing |
| Galaxy dynamics | Rotation curves RAR and BTFR |
| Disk structure | Warp vertical dispersion thickness and flaring |
| Local gravity | Solar System limits |

Calibration is allowed when declared. A result becomes a prediction when the model is frozen and the target quantity has not been used in calibration.
