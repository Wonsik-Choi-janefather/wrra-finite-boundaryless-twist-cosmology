# Finite but Boundaryless

## A WRRA Hybrid Expansion and Accumulated Twist Cosmology with Hidden Gravitational State

**Author:** Wonsik Choi  
**Version:** 1.0  
**Date:** 28 September 2026  
**Status:** Exploratory theoretical cosmology and falsifiable structural hypothesis

This repository presents an upstream WRRA cosmological hypothesis connecting finite boundaryless closure, a distributed twist connection, accumulated transport holonomy, a local twist state, and hidden gravitational stress.

The central proposal is deliberately narrower than the phrase *a Möbius universe*. A Möbius strip is the simplest visual analogy for twist distributed around an entire closed form. It does not represent one physical cut, seam, or localized flip. It has a boundary and the wrong dimension, so it is not proposed as the literal topology of the universe. The physical chain that must be tested is

```text
global closure -> distributed connection -> accumulated holonomy -> transport residue
-> twist stress -> gravitational and geometric observables
```

The paper separates expansion and twist through

$$
g_{ij}(t,\mathbf x)=a^2(t)\widetilde g_{ij}(\Theta(t,\mathbf x))
$$

and tests three cases: expansion only, pure twist, and a hybrid of both. The conditional redshift hypothesis is

$$
1+z_{\rm obs}=\frac{a_0}{a_e}e^{\Xi_T}.
$$

It is not treated as a prediction until the transport functional $\Xi_T$ is derived and frozen. The same state must also calculate additional galactic gravity, disk plane geometry, warps, vertical equilibrium, lensing, and structure growth.

The image of accumulated spatial twist was inspired while viewing **KOO JEONG A: OUSSSMOS** at Leeum Museum of Art in Seoul. ## Core distinction

> Twist selects a plane but does not define angular momentum.

The unoriented director $[n]$ satisfies $n\sim -n$. It can select a local two dimensional disk plane inside three dimensional space without introducing a prior global up direction or a rotation sign. Angular momentum remains a separate dynamical quantity.

## Scientific status

The repository does not claim a completed covariant action, a Boltzmann likelihood, or proof that cosmic expansion is illusory. It defines a model space and a falsification program. The proposal fails if one frozen twist state cannot jointly survive supernova time dilation, distance duality, Tolman dimming, BAO, CMB constraints, redshift drift, growth, lensing, galaxy dynamics, vertical equilibrium, and Solar System limits.
